# 公众号作品投票系统

基于 56 个公众号作品的在线投票收集系统，支持关键词检索、限选限投、实时结果排行。

## 快速开始

### 环境要求
- Node.js（>= 14）

### 安装与运行
```bash
npm install
npm start
```
启动后访问：http://localhost:3000

### 投票规则
- 每人每次最多选择 3 个作品
- 每个账号（手机号）最多投票 3 次
- 投票截止时间：2026年8月27日 18:00

## API 说明
- `GET /api/works`：获取作品列表
- `POST /api/vote`：提交投票（手机号 + 昵称 + 作品ID数组）
- `GET /api/account?phone=xxx`：查询账号投票情况
- `GET /api/result`：获取投票结果排行

## 云端投票收集（WPS 多维表格）

除本地网页应用外，已配置金山多维表格作为**云端公开投票入口**，外部用户可通过链接或二维码直接投票，数据云端自动汇总。

- **云端投票表单链接**：https://www.kdocs.cn/wo/sl/v14ZJzIj
- **云端多维表文件**：`公众号作品投票收集.dbt`
- **二维码**：`投票二维码.png`（指向上述链接）

云端表单说明：
- 已开启 `anyone` 编辑分享，任何人可通过链接/二维码填写投票
- 已设为可重复提交，支持同一账号多次投票（对应"限投 3 次"）
- 表单字段：昵称、手机号、所选作品（多选，含全部 56 个作品选项）
- 作品清单表内可检索查看全部作品（ID / 作者 / 作品题目）
- 投票结果在"投票记录"表内实时汇总

> 说明：金山文档表单需登录金山账号（或微信扫码）后填写。"检索作品、限选3个、限投3次、截止时间自动停止"等完整交互逻辑由本地网页应用提供。
